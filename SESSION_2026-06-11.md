### Remaining: Analytika (PivotV2) — the last slow screen
Same root cause (loads 152k raw rows of the latest month, displays only the latest day's 19k). **Measured: the jsonb-blob shortcut is ruled out** (one day = 12.5 MB; the whole month timed out). So the only forever fix is server-side aggregation — but unlike Reports' fixed aggregates, the pivot is a **generic Excel-style engine** (arbitrary 6-level nesting, cross-tab, median, 4 custom measures, drilldown). The correct approach = a decomposable-grain GROUP-BY RPC (count + sum/min/max + measure components per grain over whitelisted dims with the project join) + client rebuilds the tree from the grain, **falling back to the current raw-fetch path for median / count_distinct / high-cardinality dims** (so it can't break). That's a larger, careful build that deserves its own focused pass. It works today, just slow (~25s).
